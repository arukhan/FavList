Favorite List – Top 20 Movies
Features
- Displays a list of 20 movies with posters.
- Shows movie titles and ratings.
- Uses custom table view cells.
- Displays movie posters using Assets.xcassets.
- Highlights movie ratings with stars.


Project Structure
- `ViewController.swift` – manages the movie list and table view.
- `FavoriteCell.swift` – custom cell for displaying movie information.
- `FavoriteData.swift` – contains movie data.
- `FavoriteItem.swift` – movie model.
- `Assets.xcassets` – movie posters and app images.
